How to take them so they look like one set:

- Dark theme, 1440×900 viewport, browser chrome cropped out
- The same account and the same library in all four
- No half-loaded skeletons, no error toasts
- Save as PNG; keep each file under ~500 KB (`oxipng -o4` or `pngquant` if needed)

Shooting a light-theme variant as well is fine, but the README shows one set — pick the theme the
project looks best in and stay with it.
