# Caimack

Self-hosted сервис потокового воспроизведения собственной музыкальной библиотеки.
Бэкенд — .NET 10 (`backend/`), фронтенд — Next.js 15 (`frontend/`), база — PostgreSQL 17.

## Команды

```bash
make db        # Postgres в Docker
make backend   # API на http://localhost:5199 (dotnet watch)
make frontend  # http://localhost:3000
make dev       # всё сразу
make test      # тесты бэкенда — НУЖЕН Docker, иначе интеграционные молча пропускаются

cd backend && dotnet format                       # обязательно перед коммитом, это проверяет CI
cd backend && dotnet build MusicStreaming.slnx -c Release
```

## Устройство

Слои со строгим направлением ссылок: `Api → Infrastructure → Application → Domain`.

| Проект | Что внутри |
|---|---|
| `Domain` | Сущности, перечисления, чистые правила. **Ноль зависимостей** — не добавлять пакеты |
| `Application` | Сервисы-сценарии, DTO, настройки, порты в `Abstractions/` |
| `Infrastructure` | Адаптеры портов, EF Core, шесть фоновых процессов |
| `Api` | Контроллеры (тонкие), конвейер, композиция |

## Правила

- **Контроллер не думает.** Разобрал HTTP — позвал сервис. Появился `if` — логика не на своём месте.
- **Ошибки — исключения из `AppExceptions`**, не коды состояния. Middleware превратит их в RFC 7807.
- **Сервис не знает про HTTP.** Никакого `HttpContext` — только `ICurrentUser`.
- **Новая внешняя система = порт в `Abstractions/` + адаптер в `Infrastructure/`.**
- **Новое поле** трогает: сущность → EF-конфигурацию → миграцию → DTO → **проекцию** в
  `Common/Projections.cs`. Забыли проекцию — поле молча не появится в ответе.
- **Новая настройка** обязана получить правило `.Validate(...)` в
  `Infrastructure/DependencyInjection.cs` и строку в `.env.example`.
- **Перечисления append-only:** значения лежат в базе числами и уходят клиенту строками.
- **Часовых поясов в C# нет** (`InvariantGlobalization`) — их знает только Postgres.
- **`WarningsAsErrors=nullable`:** nullable-предупреждения ломают сборку.
- **Приложение рассчитано на один экземпляр.** Очереди, реестр воспроизведения и семафоры живут в
  памяти процесса. Вторая реплика ломает поведение молча — см.
## Комментарии

Без комментариев

XML-комментарии контроллеров и DTO попадают в схему OpenAPI и видны на `/docs`.

## Тесты

Моков нет принципиально. Чистая логика — юнит-тесты; всё остальное — интеграционные, на настоящем
Postgres в Testcontainers.
